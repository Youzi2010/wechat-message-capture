# 微信消息抓取 Skill · 安装配置说明书

> 本 Skill 不内置任何业务规则，所有参数由**安装者通过回答提问**来配置。
> 安装流程：回答下方问题 → 把答案填进 `config.json` → 测试跑通 → 挂机。
> 完整版文档见《使用说明书.md》。

## 第一步：环境准备（不可跳过）

| 依赖 | 要求 | 说明 |
|---|---|---|
| Windows | 10/11 | |
| 微信 PC 版 | **4.1.7.30**（必须） | 4.1.12+ 自绘 UI 无法自动化；装好后**关闭自动升级** |
| Python | 3.11 | |
| wxauto4 | 41.1.2 | `pip install wxauto4`（注意包名） |
| 电脑 | 可长期开机 | 挂机轮询需要 |

> ⚠️ 微信版本不符会导致所有功能不可用。装 4.1.7.30 前先备份聊天记录；安装后关闭自动更新。

## 第二步：回答配置问题（答案写入 config.json）

### 问题 1：抓取对象——需要抓取哪些群或哪些人的聊天记录？

- 群：在电脑微信里能搜索到的**群名称**（如 `config.json` 的 `targets.groups`）
- 个人：**通讯录昵称**（如 `targets.contacts`）
- 支持群 + 个人混填；留空 = 不抓这一类

### 问题 1b：只抓特定人的发言？

- `rules.senders`：填**群内昵称**列表（如 `["张三组长"]`），只抓这些人的发言，其他人一律丢弃
- 留空 = 抓群里所有人的消息
- ⚠️ 注意：昵称必须和群里显示的一字不差（含 emoji/符号）；发送者信息来自 GetAllMessage 的 sender 字段，若读消息走了 UIA 回退（拿不到发送者）则这类消息会被保守丢弃

### 问题 2：关键词——需要抓取哪些关键词？排除哪些词？

- 关键词（`rules.keywords`）：消息**命中任一关键词**才抓取。留空 = 全部消息都抓
- 排除词（`rules.exclude_keywords`）：消息**命中任一排除词**就丢弃（如不想要的广告/闲聊）。留空 = 不排除
- 提示：关键词不要太短（如单个"工"会误伤大量消息），建议 2 字以上

### 问题 3：监测频率——多久监测一次？

- `poll.interval_seconds`：两次轮询间隔（秒）。例：3600 = 每小时一次，1800 = 半小时，300 = 5 分钟
- ⚠️ 频率越高效用越高，但**封号风险越大**。建议 ≥600 秒（10 分钟），挂机号 1 小时为宜

### 问题 4：汇总发送——汇总发到哪个微信？一天几发？几点发？

- `summary.send_to`：接收人**通讯录昵称**（如自己的小号/文件传输助手/某群）。用电脑微信能搜到的名字
- `summary.frequency`：`daily` = 一天一发；`multiple` = 一天多发
- `summary.schedule`：发送时刻。daily 填一个（如 `"20:00"`）；multiple 填多个（如 `["09:00","14:00","20:00"]`）
- `summary.enabled`：false = 只抓取入库，不自动发汇总

### 问题 5：时间范围——抓取几天内的消息？

- `time_range_days`：只抓最近 N 天内的消息（默认 3）。调大 = 可回溯更多历史，但首次抓取更慢

### 补充问题（按需）

| # | 提问 | 配置 | 说明 |
|---|---|---|---|
| 6 | 汇总是否必须带手机号？ | `rules.require_phone` | 招工/业务类开 true；普通消息 false |
| 7 | 是否需要实时推送（抓到就发）？ | 当前为定时汇总模式 | 实时模式需另配 cron 高频触发，风险更高，不建议 |
| 8 | 库里的数据保留多久？ | 手动清理 db 文件即可 | 默认不自动删；文件小可长期保留 |
| 9 | 风控等级选哪个？ | `poll.sample_ratio` / `night_stop` | 保守 = 采样低+夜间停；激进 = 采样高+不停（不推荐） |
| 10 | 掉线/故障告警通知谁？ | 心跳 cron 的 `--who` | 默认发到 `summary.send_to` |

## 第三步：测试

python wx_probe.py

# 2. 单轮抓取（看有没有抓到消息）
python pipeline.py --once --verbose

## 第四步：挂机

- Windows 计划任务定时跑 `pipeline.py --once`（推荐，防重叠）
- 或 `python pipeline.py --loop` 常驻
- 配置心跳监控（每 4 小时 wx_probe + 告警）

## 常见问题

**Q：抓不到消息？**
A：先 `python wx_probe.py` 确认微信在线+版本对；再确认目标名字和电脑微信搜索框里输入的名字完全一致（含 emoji/符号）；最后确认关键词是否太严。

**Q：汇总太长？**
A：自动按 `summary.max_chars`（默认 1800）分段发送。

**Q：会被封号吗？**
A：任何微信自动化都有风险。本 Skill 已内置：随机采样、随机抖动、夜间停轮、模拟人类节奏、锁版本。遵守：频率别太激进、挂机号别是新号、别批量加群（一天 ≤5-10 个）。

**Q：想抓的群在"折叠的聊天"里？**
A：没问题，脚本用搜索式打开（ChatWith），不依赖会话列表。

**Q：抓取记录存哪里？**
A：`db/messages.db`（SQLite）。可用任意 SQLite 工具查看。

**Q：按发送者过滤抓不到？**
A：先跑 `python diag_sender.py "群名"` 看实际 sender 字段值，把群内昵称一字不差填进 `rules.senders`。
